## 六个模块与选定模型

| 模块 | 课程阶段 | 对应经典环节 | 选定模型 | 输出接口 |
|---|---|---|---|---|
| M1 道路图像采集与相机标定 | 阶段二 | §4.1 传感硬件与标定 | OpenCV Zhang 平面标定 + cv2.undistort | DatasetManifest、CalibratedFrame |
| M2 图像预处理与质量评价 | 阶段三 | 感知前端预处理 | Zero-DCE Tiny + CLAHE | ImageVariantSet、QualityReport |
| M3 特征检测与局部特征匹配 | 阶段四 | §4.2.3 定位与自运动估计（几何特征提取） | SIFT + FLANN + RANSAC | MatchResult |
| M4 2D 目标检测 | 阶段四 | §4.2.1 目标检测 | YOLOv12-N | DetectionSet |
| M5 多目标跟踪 | 阶段四–五 | 多目标跟踪 | ByteTrack + UCMCTrack | TrackSet |
| M6a 2D 语义分割 | 阶段五 | §4.2.2 语义分割 | PIDNet-S | SegmentationMap |
| M6b 场景理解与拓扑推理 | 阶段五 | §4.3 场景表示 | 规则化 2D 场景图 | SceneGraph2D |
| 验证层 | 阶段六 | Safety Monitor | 切片评测 + 失败标签 + 降级策略 | EvaluationRecord |

M6a 与 M6b 同属第六个模块（语义分割与场景理解）的两个子块：M6a 直接消费 M2 的图像版本，与 M4 检测**并行**；M6b 消费 M5 的轨迹、M6a 的区域掩码与 M3 的几何证据。

## 双通路组织（腹侧 / 背侧）

| 通路 | 组成 | 回答的问题 |
|---|---|---|
| 腹侧通路 what | M4 2D 目标检测 + M5 多目标跟踪 | 有什么目标、它们如何随时间移动 |
| 背侧通路 where/how | M3 特征检测与匹配（几何与自运动估计）+ M6a 2D 语义分割（道路、可行驶区域、车道标线等背景结构） | 自车如何运动、道路与车道线在哪里 |
| 汇合点 | M6b 场景理解与拓扑推理 | 对象—区域隶属、前后左右、相邻与冲突 |

数据流：`输入 → M1 → M2 →｛M3 ∥ M4 ∥ M6a｝→ M5（腹侧）→ M6b（两路汇合）→ 结构化场景描述`；阶段六为环绕六个模块的验证层，按数据切片汇总指标、延迟与失败标签，并把质量门控结论回注 M2。

## 几条约定

- 实线为运行时数据流，虚线为可选几何依赖（M3 的单应矩阵用于 M5 相机运动补偿与 M6b 几何证据）与评测依赖。
- 模块之间只传字段级结构化契约，不传高维特征张量；接口字段与不变量见阶段一《架构决策文档》第六节。
- 需要区分：本项目的"特征提取"指 **M3 的局部特征（SIFT）检测与匹配**，用于几何与自运动估计，不是检测与分割共享的 backbone 特征——这是为模块可替换性做的取舍。
- 裁剪说明：规划、行为仲裁与运动控制不在课程范围内；经典架构中的定位建图（SLAM）由 M1 标定与 M3 几何估计承担。
