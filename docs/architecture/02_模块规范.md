# 02 模块规范

本文件定义每个模块的**职责边界、输入输出与约束**。所有条目与实现无关：具体用什么算法、什么模型、什么阈值，属于实施阶段的决策，不写在这里。

通用约定：

- 「输入」指必须满足的前提条件，不只是字段；「输出」指对下游的承诺（后置条件）。
- 每个模块都必须满足 P2（只传结构化结果）、P3（失败显式）、P4（可选输入缺失时降级）。
- 「验收维度」只定义**看什么**，具体阈值与基线数值在实施阶段填写。

模块总览：M1 采集与相机标定 → M2 图像预处理与质量评价 →｛M3 几何特征提取与自运动估计 ∥ M4 多目标检测与跟踪 ∥ M5 语义分割｝→ M6 场景理解与拓扑推理；评测与验证贯穿。

---

## M1 采集与相机标定

| 项 | 内容 |
|---|---|
| 职责 | 组织输入样本，建立统一的图像坐标系与标定状态，并对外提供数据来源与许可信息 |
| 不做 | 不做图像内容处理；不做目标或区域的语义判断；不假设输入自带可靠标定 |
| 输入 | 图像 / 视频序列、相机参数（可选）、数据来源与许可信息 |
| 输出 | `CalibratedFrame`（含坐标系与标定状态）、`DatasetManifest`（版本、切分、来源、许可、切片标签） |
| 约束 | 标定状态必须显式（有效 / 缺失 / 过期）；样本必须可追溯到来源与许可；切片标签必须随样本传递 |
| 验收维度 | 坐标系一致性；标定精度（重投影意义下）；标定可用率；数据清单完整性与可追溯性 |
| 关键失败模式 | 缺少标定信息、坐标系标注错误、样本与标注版本不一致 |
| 待填 | 具体标定方式与参数、数据来源与版本、切分方案 |

## M2 图像预处理与质量评价

| 项 | 内容 |
|---|---|
| 职责 | 产出下游可用的图像版本（保留原始版本），并给出质量结论与门控决策 |
| 不做 | 不改变图像的空间几何（几何校正属 M1）；不输出任何语义结果；不强制下游使用处理后版本 |
| 输入 | `CalibratedFrame` |
| 输出 | `ImageVariantSet`（多个图像版本 + 默认版本）、`QualityReport`（质量指标 + 门控决策 + 理由） |
| 约束 | 原始版本必须始终存在；门控决策必须带理由；处理参数必须随版本记录，便于复现 |
| 验收维度 | 图像质量指标；处理后对下游任务指标的影响（正向或中性）；处理耗时；门控决策的一致性 |
| 关键失败模式 | 处理放大噪声或引入伪影；门控决策与下游收益不一致；处理后版本不可复现 |
| 待填 | 处理手段与强度、质量指标集合、门控阈值、对照方案 |

## M3 几何特征提取与自运动估计

| 项 | 内容 |
|---|---|
| 职责 | 由图像对估计帧间几何变换（含自车运动），并给出可信度。**唯一消费者是 M4 跟踪子块（运动补偿）与 M6（几何证据）；不参与检测与分割推理** |
| 不做 | 不输出任何语义类别；不做目标身份关联；不做像素级分类；几何不可用时不得输出"看起来可信"的结果 |
| 输入 | `ImageVariantSet`（成对帧） |
| 输出 | `MatchResult`（对应关系、内点信息、几何变换、状态与可信度） |
| 约束 | 必须携带状态（可用 / 不可靠 / 失败）与输入版本标识；几何量只在标定有效的条件下才用于物理尺度推断 |
| 验收维度 | 几何精度（残差意义下）；内点比例；可用率；耗时；在弱纹理 / 重复纹理 / 快速运动下的退化行为 |
| 关键失败模式 | 弱纹理或重复纹理导致错误对应；快速运动导致匹配失败；标定失效时几何量被误用 |
| 待填 | 特征与匹配方式、外点剔除策略、可用性判据与阈值 |

## M4 多目标检测与跟踪

M4 含两个子块，共用同一模块边界与对外接口。**检测与跟踪合成一个模块**，因为它们共享同一输入、同一评价对象（目标），且检测结果是跟踪的唯一前置；同时保留各自的评测口径，避免"检测差"与"关联差"无法区分。

### 共用约束

| 项 | 内容 |
|---|---|
| 模块职责 | 在连续帧上给出实例级目标，并把它们关联成带身份与状态的轨迹 |
| 不做 | 不做像素级分类（属 M5）；不做空间关系推理（属 M6）；不允许把不可靠轨迹当作确定事实 |
| 输入 | `ImageVariantSet`（连续帧）；可选 `MatchResult`（用于相机运动补偿） |
| 输出 | `DetectionSet`（检测子块，模块内部接口，同时对外可读）、`TrackSet`（跟踪子块） |
| 约束 | 输出必须带坐标系、输入图像版本与实现标识；类别必须引用类别模式；轨迹状态必须显式；两子块的指标必须能分别统计 |
| 待填 | 检测实现与规模、关联实现与代价设计、是否启用几何补偿、置信度阈值、类别集合 |

### 子块一：检测

| 项 | 内容 |
|---|---|
| 职责 | 在单帧图像上输出实例级目标（类别 + 位置 + 置信度） |
| 验收维度 | 精度（按面积 / 距离分组）；召回与漏检；耗时与资源占用；不同切片下的稳定性 |
| 关键失败模式 | 远距离小目标漏检；夜间或模糊条件下置信度整体漂移；类别体系与下游不一致 |

### 子块二：跟踪

| 项 | 内容 |
|---|---|
| 职责 | 把逐帧检测关联成稳定轨迹，管理轨迹身份与状态，输出时序证据 |
| 验收维度 | 身份保持能力（ID 切换次数）；轨迹连续性与断裂率；遮挡与相机运动下的稳定性；耗时 |
| 关键失败模式 | 遮挡导致身份切换；相机运动未补偿导致静止目标被误判为运动；轨迹碎片化 |

## M5 语义分割

| 项 | 内容 |
|---|---|
| 职责 | 输出像素级区域结构（类别 + 区域掩码） |
| 不做 | 不做实例检测与跨帧关联（属 M4）；不做关系推理（属 M6） |
| 输入 | `ImageVariantSet` |
| 输出 | `SegmentationMap`（帧标识、输入版本、类别图、类别模式引用） |
| 约束 | 类别语义必须经类别模式显式映射；输出分辨率与坐标空间必须显式记录；细长结构（如车道标线）需要单独口径时必须在模块内说明 |
| 验收维度 | 区域精度（含边界）；细长结构表现；类别映射正确性；耗时 |
| 关键失败模式 | 细长结构断裂；类别映射错位（编号相同、语义不同）；边界区域连续性被破坏 |
| 待填 | 分割实现与规模、类别集合与映射表、边界与细长结构的评价口径 |

## M6 场景理解与拓扑推理

| 项 | 内容 |
|---|---|
| 职责 | 融合轨迹、区域与几何证据，输出结构化场景描述（对象—区域关系图）；是两条通路的汇合点与唯一对外结构化输出 |
| 不做 | 不做检测 / 跟踪 / 分割本身；不输出证据不足的关系；不做规划与决策 |
| 输入 | `TrackSet`、`SegmentationMap`、可选 `MatchResult` 与标定状态 |
| 输出 | `SceneGraph2D`（节点、关系边、证据、置信度、几何状态、来源） |
| 约束 | 只输出证据充分的关系；几何失效时显式降级为图像平面关系；每条边必须可追溯到证据来源 |
| 验收维度 | 区域隶属关系正确性；相对位置关系正确性；图结构合法率；降级判定的准确性 |
| 关键失败模式 | 标定失效或轨迹不可靠时输出伪几何关系；关系类型覆盖不足；图结构自相矛盾 |
| 待填 | 关系类型集合与判定规则、证据类型与置信度口径、降级判定条件 |

## 评测与验证

| 项 | 内容 |
|---|---|
| 职责 | 按数据切片评测各模块、记录失败标签、归因到模块与子块、把门控与降级结论回注 |
| 不做 | 不产出被下游消费的运行时数据；不替代模块自身的实现；不宣称达到某个安全等级 |
| 输入 | 各模块输出、评测真值、运行配置与实现标识 |
| 输出 | `EvaluationRecord` |
| 约束 | 任一总体指标必须可追溯到模块、切片与失败样本；检测与跟踪的指标必须分开统计；实现与配置版本必须随记录保存 |
| 验收维度 | 覆盖率（切片与模块是否齐全）；可追溯性；失败标签的一致性；结论对架构调整的指导性 |
| 待填 | 切片定义、指标集合、失败标签体系、评测流程与自动化程度 |
