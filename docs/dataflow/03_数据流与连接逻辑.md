# 03 数据流与连接逻辑

本文件定义六个模块之间如何连接、各连接传递什么、缺失时如何降级。接口字段以本文件的连接和不变量为依据，详见 [`../interface/04_接口规范.md`](../interface/04_接口规范.md)。

## 3.1 基本约定

| 约定 | 规则 |
|---|---|
| 连接边界 | 模块之间只能通过本文定义的结构化接口通信，不共享隐式全局状态。 |
| 数据粒度 | 运行级、序列级、帧级和相邻图像对级；粒度必须在接口中可识别。 |
| 对齐键 | 图像结果使用 `sequence_id + frame_id + variant_id + coordinate_space`；图像对使用 `frame_a + frame_b`。 |
| 版本一致 | M3、M4、M5 使用 M2 为当前帧选出的同一个 `default_variant`。 |
| 时间方向 | 结果只能使用当前帧及过去帧；M3 的结果服务于 `frame_b` 及之后，不使用未来帧。 |
| 离线处理 | 允许等待输入，但不允许用其它帧、其它序列或其它版本静默顶替缺失数据。 |
| 降级原则 | 可选边缺失时保留可用主链路，并在最近的接口上记录状态、原因和未使用的证据。 |

## 3.2 模块处理单元

| 模块/子块 | 处理单元 | 触发条件 | 内部状态 |
|---|---|---|---|
| M1 输入接入与标定状态管理 | 序列 / 帧 | 媒体和清单可读 | 帧清单、标定引用、序列元数据 |
| M2 输入规范化与图像质量评价 | 帧 | `CalibratedFrame(t)` 到达 | 图像版本、质量指标、门控决策 |
| M3 帧间几何估计 | 相邻图像对 | 同序列、同版本的 `t-1,t` 齐备 | 参考帧和匹配缓存 |
| M4 检测子块 | 帧 | `ImageVariantSet(t)` 到达 | 默认无跨帧状态 |
| M4 跟踪子块 | 帧 / 序列 | `DetectionSet(t)` 到达 | 活跃轨迹、预测状态、生命周期 |
| M5 全图逐帧语义分割 | 帧 | `ImageVariantSet(t)` 到达 | 第一版无时序状态 |
| M6 2D 场景结构融合 | 帧或明确的短窗口 | 对齐后的 M4/M5 输入到达或等待上限 | 当前场景图和降级记录 |
| 评测与验证 | 运行级 | 离线触发 | 只读指标和失败记录 |

## 3.3 连接清单

### 必需数据边

| 编号 | 源 → 目标 | 接口 | 说明 |
|---|---|---|---|
| E01 | 外部输入 → M1 | 外部输入 | 视频/图像序列、来源许可、可选标定引用 |
| E02 | M1 → M2 | `CalibratedFrame` | 带帧标识、尺寸、坐标空间和标定状态的输入帧 |
| E03 | M1 → 全链路 | `DatasetManifest` | 运行级清单、切分、来源和切片标签 |
| E04 | M2 → M3 | `ImageVariantSet` | 相邻帧且同一 `variant_id` 的图像版本 |
| E05 | M2 → M4 | `ImageVariantSet` | 当前帧统一默认版本，供检测子块使用 |
| E06 | M2 → M5 | `ImageVariantSet` | 当前帧统一默认版本，供分割使用 |
| E07 | M4 检测 → M4 跟踪 | `DetectionSet` | 当前帧检测供关联，检测指标单独评测 |
| E08 | M4 跟踪 → M6 | `TrackSet` | 带轨迹 ID、状态和当前 bbox 的目标输入 |
| E09 | M5 → M6 | `SegmentationMap` | 与源帧坐标对齐的类别区域输入 |
| E10 | M6 → 对外输出 | `SceneGraph2D` | 当前版本唯一的结构化场景输出 |

### 可选依赖边

| 编号 | 源 → 目标 | 接口/字段 | 缺失时行为 |
|---|---|---|---|
| E11 | M1 → M6 | `CalibratedFrame.calibration.status` | 没有有效标定时只输出图像平面关系 |
| E12 | M3 → M4 跟踪 | `MatchResult` | 不做几何补偿，回退到普通运动模型和检测关联 |
| E13 | M3 → M6 | `MatchResult` 的状态 | 不使用匹配几何证据，记录 `match_unreliable` 或 `match_missing` |

### 评测和控制边

| 编号 | 源 → 目标 | 内容 | 约束 |
|---|---|---|---|
| E14 | 评测与验证 → 各模块 | 只读采样 | 不修改运行时数据 |
| E15 | 评测与验证 → M2 | 门控策略调整 | 只改变配置策略，不改变接口语义 |
| E16 | M2 → 评测与验证 | `QualityReport` | 记录质量、版本选择和处理结果 |
| E17 | 评测与验证 → 归档 | `EvaluationRecord` | 保存指标、失败样本和版本引用 |

## 3.4 主数据流和时序

```text
外部媒体 + DatasetManifest + 可选标定
                  │
                  ▼
        M1 输入接入与标定状态管理
                  │ CalibratedFrame
                  ▼
        M2 输入规范化与图像质量评价
                  │ ImageVariantSet(default_variant)
          ┌───────┼────────┐
          ▼       ▼        ▼
        M3      M4 检测    M5 分割
          │       │        │
          │       ▼        │
          │    M4 跟踪     │
          │       │        │
          └───────┴────────┘
                  ▼
        M6 2D 场景结构融合
                  │ SceneGraph2D
                  ▼
                对外输出
```

处理顺序与约束：

1. M1 为每帧生成稳定身份；M2 先做输入检查，再选择一个默认版本。
2. M2 的 `default_variant` 同时供 M3、M4、M5；支路不能各自重新选择版本。
3. M3 消费 `pair(t-1,t)`，可把结果交给第 t 帧跟踪补偿；它不是 M4/M5 的硬前置。
4. M4 先产出当前帧 `DetectionSet`，跟踪子块再与历史轨迹关联并产出 `TrackSet`。
5. M5 输出源帧坐标对齐的 `SegmentationMap`，不维护目标 ID。
6. M6 只聚合同一帧、同一版本、同一坐标空间的 `TrackSet` 和 `SegmentationMap`；任何不一致都拒绝静默聚合。
7. 第一版 M6 以单帧为默认窗口；若实现使用短窗口，必须显式记录窗口帧列表和是否使用未来帧。

## 3.5 M4 的检测—跟踪连接

```text
ImageVariantSet(t)
          │
          ▼
   全图逐帧检测
          │ DetectionSet(t)
          ▼
   轨迹预测与关联  ◄── MatchResult(t-1,t)（可选）
          │
          ▼
      TrackSet(t)
```

- 检测回答“当前帧有哪些目标”；跟踪回答“哪些目标延续了历史身份”。
- 检测缺失时不能复制上一帧的检测框；跟踪可按生命周期输出 `lost` 或 `unreliable`。
- M3 失败时跟踪仍运行，但 `association` 必须标记 `motion_compensation_used=false`。
- 切换 `sequence_id` 时必须清空活跃轨迹，禁止跨视频串联 ID。

## 3.6 M4/M5 → M6 的对齐规则

M6 在聚合前执行以下检查：

| 检查 | 通过条件 | 失败行为 |
|---|---|---|
| 帧 | `sequence_id` 和 `frame_id` 相同 | 不聚合，列出 `frame_mismatch` |
| 图像版本 | `variant_id` 相同 | 不聚合，列出 `variant_mismatch` |
| 坐标空间 | `coordinate_space` 相同且可解释 | 不聚合，列出 `coordinate_space_mismatch` |
| 尺寸映射 | M5 的 `alignment_ref` 可映射到 M4 源帧 | 不生成对象—区域关系 |
| 状态 | M4/M5 结果可用 | 只保留有证据的关系，并记录缺失输入 |

没有深度和地面模型时，M6 只计算图像平面关系：区域归属、左右、重叠和出现关系。不得把这些关系改名为前后、距离、冲突或风险。

## 3.7 失败与降级传播

| 失败条件 | 直接影响 | 下游行为 | 必记内容 |
|---|---|---|---|
| 标定缺失/过期 | M2 校正版本、M6 几何语义 | 保留 `raw`，M6 为 `image_plane` | 标定状态和原因 |
| M2 处理失败 | E04/E05/E06 | 统一回退到 `raw` | `gate_decision=use_raw`、原因 |
| M3 不可靠 | E12/E13 | 跟踪不补偿，M6 不使用几何证据 | MatchResult 状态、消费方降级标记 |
| 检测失败/缺失 | E07/E08 | 不伪造检测；轨迹进入生命周期降级 | `detection_missing`、轨迹状态 |
| 轨迹不可靠 | E08 | 不用该轨迹单独生成 M6 关系 | 排除原因 |
| 分割失败/未对齐 | E09 | M6 不生成对象—区域关系 | `missing_inputs`、对齐失败原因 |
| 证据不足 | E10 | 不补边，保留缺失或不确定记录 | 证据、置信度和规则版本 |

降级只能向下游传播，不能在中间模块被“修饰”为正常结果。

## 3.8 连接级不变量

| 编号 | 不变量 | 接口落点 |
|---|---|---|
| C1 | 每个结果都能回答来自哪一帧 | `sequence_id`、`frame_id` |
| C2 | 图像结果都能回答来自哪个版本和坐标空间 | `variant_id`、`coordinate_space` |
| C3 | 每个结果都能追溯实现和配置 | `producer_ref`、`config_ref` |
| C4 | 几何语义不超出标定和变换的可信范围 | `calibration.status`、`geometry_status` |
| C5 | 失败和缺失可被下游识别 | `status`、`state`、`missing_inputs` |
| C6 | 可选边缺失不改变必需边含义 | 明确的降级语义 |
| C7 | M4/M5 结果可无歧义聚合 | 四元对齐键 |
| C8 | 关系能追溯到证据 | `edges[].evidence`、`provenance` |

## 3.9 实现阶段待填项

轨迹生命周期阈值、质量门控阈值、M3 可用性判据、M6 关系判定阈值、短窗口长度、类别模式和切片定义属于实现参数。它们可以调整，但不得改变本文件规定的连接方向、对齐规则和能力边界。
